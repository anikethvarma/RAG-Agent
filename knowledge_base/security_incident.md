# Security Incident Reporting

Owner: Security Team

## Phishing
If you receive a suspicious email, use the "Report Phish" button in your mail client. Do not click links or open attachments in the email.

## Reporting an incident
Suspected security incidents must be reported to security@helixcloud.example. For anything urgent, such as an active account takeover, page the security on-call engineer through PagerDuty.

## MFA codes
Never share multi-factor authentication (MFA) codes with anyone, including people claiming to be from IT. Helix Cloud staff will never ask for your MFA code.
